Amazon India sales analysis

Description:
    Performed exploratory data analysis on Amazon India sales dataset from kaggle, To find some insights and answers for previously stated questions.

Stated Questions:
    * How many unique orders
    * How frequently do orders get canceled
    * Percentage of canceled orders
    * Does sales increase in a specific month
    * Top five profitable states
    * Most shipment service levels used
    * Most ordered category
    * How often b2b transactions happen
    * Which category do businesses order from Amazon
    *Which category has the highest profitability among regular customers
    * Does free shipping promotion increase orders

Table of contents:
    -Importing needed libraries.
    -Reading CSV file
    -Assessing data and building intuition, exploring its shape, columns, and other attributes.
    -Performing data cleaning, Filling NULL values, and Standardizing entries in the ship-City column.
    -Answering the stated questions.

Libraries& software used:
-Pandas.
-Matplotlib.
-Seaborn.
-Jupyter Notebook
